EMPViewer

A portable desktop viewer for .eml, .msg, .pst and .ost mail files. No installer, no Chromium, instant start.

Download View on GitHub

macOS (Apple Silicon & Intel) · Windows  |  MIT licensed  |  Python 3.11+ / PySide6

Features

📬

Four formats, one app

.eml via the standard library, .msg via extract_msg, and .pst/.ost through a pluggable backend — auto-detected at runtime.

🧩

Built-in PST reader

A pure-Python MS-PST reader with no dependencies is the default. libpff or a readpst binary are used in preference when present, but never required.

🛡️

Privacy by default

Remote images and tracking pixels are blocked until you click Load remote content. Inline cid: images always render offline.

⚡

Never blocks

Every parse and every PST folder/message load runs on a worker thread — the UI stays responsive even on large .pst files.

📎

Attachments

Click to open with the OS default app (a copy lands in a per-session temp dir wiped on exit); right-click for Save As….

🖱️

Drag & drop + file association

Drop any supported file onto the window. Register as the double-click handler on Windows and macOS.

Formats

.eml

Standard-library email module — always available, zero dependencies.

.msg

extract_msg: headers, HTML/text body, inline images, attachments, RTF fallback.

.pst / .ost

Built-in pure-Python reader (Unicode PST/OST; none / permute / cyclic encryption). Falls back to libpff or readpst if importable / on PATH. Modern profile-encrypted .ost is reported cleanly as unreadable rather than crashing.

Set as the default mail-file viewer

macOS

  1. Move EMPViewer.app to /Applications and open it once.
  2. Select an .eml file in Finder → ⌘I → Open with → EMPViewer → Change All…
  3. Repeat for .msg / .pst / .ost. Or run packaging/macos/set-default.command (uses duti if installed).

Windows

  • EMPViewer.exe --register — register as a handler
  • EMPViewer.exe --set-default — register + open Settings ▸ Default apps
  • EMPViewer.exe --unregister — remove
  • Windows won't silently take a type another app owns (Outlook owns .msg/.pst) — confirm the switch once in Default apps.

Full distribution & default-handler guide (portable vs installer, Windows & macOS, enterprise / GPO): docs/DAGITIM.md (Turkish).

Build & run from source

# run from source
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py                    # empty window
python main.py path/to/mail.eml   # open a file

# package a portable binary
python build.py                   # Windows -> EMPViewer.exe   macOS -> EMPViewer.app
python build.py --onedir          # faster cold start
python build.py --dmg             # macOS: also build a .dmg
python build.py --installer       # Windows: EMPViewer-Setup.exe via Inno Setup

No extra setup for any format — .pst/.ost are read by the built-in parser. libpff-python or a readpst binary, if present, are used in preference but are entirely optional.

  • Approvers: Erdem Ovali (@erdemovali) — each signing request is approved manually before a release is signed.

Binaries are built only from the source in the GitHub repository, by the GitHub Actions workflows in .github/workflows/.

Privacy: this program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Remote content in messages (images, tracking pixels) is blocked until you explicitly click Load remote content. See also SECURITY.md.
